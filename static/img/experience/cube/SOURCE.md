# 三图点阵素材来源

三张图片由网站作者提供，用于个人网站开屏的黑白点阵展示。

| 文件 | 来源 |
| --- | --- |
| `avatar.webp` | 网站原头像 `static/img/uploads/b_22cb441f64208eaff55e9670d85922ab.jpg` |
| `portrait-a.webp` | 用户提供的 `IMG_9948.JPG`，白发狐耳人物 |
| `portrait-b.webp` | 用户提供的 `4FF87EBF-D20B-475C-BF8B-4285D16D2B2C.png`，花丛中的蓝灰发人物 |

处理方式：图像编辑工具生成透明轮廓蒙版，最终颜色数据重新取自原图；保留原图的五官、服饰与画面内容，仅将背景透明化。导出为 512×512 WebP，保留 alpha 通道。人物体积在 WebGL 运行时由分层深度生成，素材本身不是完整三维模型。

背景移除蒙版与原始素材保留在作者本地。原图及角色的权利归各自权利人所有；本目录不为原画或角色提供额外的再分发授权。
