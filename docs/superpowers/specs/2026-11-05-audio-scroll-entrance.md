# 北天博客：滚动开屏与音乐点阵首版

参考 pront.site 的首屏与内容区滚动衔接。保留本博客的黑白角色、原蓝色背景及既有文章玻璃转场。

## 视觉与交互

- 黑白星海围绕原人物，低频推动投影轨道扩散，中频抬升两侧光点，高频点亮细粒。中央留白保护脸部辨识度。
- 按用户反馈增强外围密度，1440×1000 下约 5684 个候选点，390×844 下约 2232 个候选点，实际可见点受中央留白、边缘裁切和亮度影响。使用真实频谱增益与低频瞬态推动更明显的位移。
- 从用户提供的 `Gargantua_BGM.mp4` 提取 3、15、30 秒代表帧，选第 3 秒压缩为 `static/img/experience/blackhole.webp`，CSS 转为黑白底图；不加载整段视频，不引入它的音轨。
- 左侧文字“WELCOME TO / 北天的博客”，手机上移至人物上方。右下角常驻播放、暂停与音量控制。
- 音乐来自用户提供的 HOYO-MiX《太空漫步 Space Walk》，位于 `static/audio/space-walk.mp3`。默认尝试有声自动播放；浏览器拦截时提示用户点击启用，手动暂停后不被其他点击重新启用。频谱来自 Web Audio AnalyserNode，不模拟音乐节拍。未播放时保留缓慢环境运动。
- 下滚约一屏使点阵、黑色舞台逐步消融，蓝色背景和主页逐步出现；向上滚动可逆向恢复。提示按钮可供键盘用户跳至主页。
- 快捷卡片逐张错开揭示，文章卡片进入视口后揭示。普通文章入口仍使用既有玻璃转场。
- 播放器在各页面常驻，音量保存在本机；本版不承诺跨完整页面导航无缝续播。
- 桌面为人物居左、黑洞居右，手机黑洞移至人物上方。取消重复的固定光点、扫描线、光束和装饰轨道，只保留真实音频点阵。
- 同一份频谱驱动主页流体的流动速度、扩散幅度与亮度，暂停后平滑回到常态。测试覆盖自动播放允许、被拦截后的首次交互、手动暂停不被页面点击恢复，以及实际 GPU 流速 uniform 的变化。
- 后续用户拒绝连续明暗人物版，要求恢复明确像素感：`hologram.ts` 已恢复既有 `pixel-light-matrix` 版本，Astra 的尝试仅归档在本地验证目录。
- 主页流动改为真实背景图取色的水彩颜料场：仅鼠标/自动笔触所在区域拾取颜色，随后随速度场运输、扩散和衰减；不再对整屏持续重新取色。湿边和保留色相的局部明暗增益提供可见性，音乐与鼠标共同控制流场。
- 取色验证覆盖红/蓝/绿/橙四象限、2000×900 宽图在900×900视口的居中cover、混合指针设备鼠标轨迹实际进入GPU。真实背景截图对比见 `watercolor-local-stroke.png`，关闭流动层对比见 `watercolor-local-base.png`。
- 隐藏页面、离开开屏后停止不可见点阵绘制；减少动态设置保留直接阅读。
