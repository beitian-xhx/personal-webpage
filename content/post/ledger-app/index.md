## 项目简介

**背景**：想要一款属于自己的私人记账工具——既能导入微信、支付宝导出的账单 Excel，又希望自动分好类、直观看到每个月钱花在哪。对比了多种技术方案（开发难度、Excel 兼容性、打包便利性）后，选定 Electron + React + Ant Design + Recharts 技术栈从零开始搭建。

**核心功能**：

- **账单导入**：支持微信、支付宝等平台导出的 `.xlsx` / `.csv` 文件。针对真实账单文件（表头不在第一行、日期有三种格式）做了解析优化，采用「解析 → 预览 → 提交」三步向导，导入前可修正分类、勾选或丢弃记录。
- **自动分类**：内置游戏 / 医疗 / 教育 / 旅行 / 日用 / 其它六大预设分类，配套数百个关键词规则（平台名、商家名、商品词等）自动归类；「其它」里的记录可随时手动重分配。
- **统计分析**：按月汇总支出，饼图看分类占比、柱状图对比分类金额、折线图追踪每个分类的跨月趋势，并支持年度总览。
- **多账本**：不同账本数据完全独立隔离，互不共享；每个账本自带一套分类。
- **安全删除**：删除操作采用「软删除 + 30 天回收站」，误删可恢复，应用启动时自动清理过期数据。

**工程特点**：数据使用自研的零依赖 JSON 文件数据库，整个应用做成便携版（数据目录随 exe 走），副本与原件完全独立，可直接复制给他人使用，无需配置任何环境。开发过程沉淀了 15+ 个可复用的工程模式（导入向导状态机、表头关键词定位、跨页面数据刷新等）。

## 成果

- ✅ **交付即用**：打包成可独立运行的 `轻松记账.exe`（便携版，免安装、数据随行），Windows 11 上双击即用。
- ✅ **需求全覆盖**：导入、自动分类、月度/年度统计图表、分类管理、回收站——原始需求逐条落地。
- ✅ **经真实数据验证**：导入与自动分类管线经过 300+ 笔真实微信账单验证；目前已实际使用中（建有多本账本）。
- ✅ **解决真实世界难题**：啃下了微信/支付宝账单格式差异、Excel 日期多格式解析、跨账本数据隔离、Electron 打包等坑。
- ✅ **能力沉淀**：把开发中遇到的普遍性问题与解法写成 15+ 篇经验记忆（导入向导、软删除、表头检测等），可直接复用于后续项目。
