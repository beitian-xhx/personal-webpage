## 项目简介

基于 YOLO 的实时游戏画面人物检测与吸附 Demo，适用于直播、录屏、复盘等需要自动跟拍画面中人物的场景。纯 ctypes Win32 抓屏，无第三方捕获库依赖；双缓冲抓屏线程让捕获与推理并行。

## 运行逻辑

`游戏窗口/屏幕 → BitBlt 捕获 → YOLO person 检测 → 头部中心定位 → 目标选择(半径+锁定) → EMA 平滑 → 吸附跟随`

- 后台线程持续抓取游戏窗口客户区（或手动区域/全屏），只保留最新帧
- YOLO 只检测 COCO `person` 类，取人物框水平中心 + 可调垂直比例作为吸附点
- 屏幕中心进入吸附半径后锁定最近目标；目标丢失自动重选，半径内无目标则完全自由
- 吸附点与移动量两级 EMA 平滑 + 单帧限幅 + 移动 CD，兼顾跟手与防抖

## 吸附功能

Tkinter 置顶控制面板实时调节 **吸附强度 / 灵敏度 / 吸附半径 / 吸附点位置 / 点平滑 / 移动平滑 / 移动 CD**，状态行实时显示 FPS、检测人数与目标距中心距离；取消勾选「启用吸附」即暂停，视角完全自由。

## 技术要点

- 纯 ctypes `BitBlt` 抓屏，进程级 DPI 感知，适配高分屏
- `yolo26n` 实时人物检测（COCO person），仅人物类推理
- `SendInput` 合成相对移动实现视角平滑吸附
- 目标点 EMA 与移动量 EMA 双平滑，抑制检测框抖动与高频微移
